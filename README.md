# PfandTascherl

**Dein Pfand. Deine Wirkung.**

PfandTascherl ist der Prototyp einer mobilen Web-App, die digitales Pfandsammeln mit gezielten Spenden verbindet. Ziel ist es, die Rückgabe von Pfandgebinden einfacher mit sozialem Engagement zu verknüpfen.

## Funktionen

- Pfandguthaben über Demo-QR-Codes erfassen
- Guthaben und Transaktionen verwalten
- Individuell oder automatisch an ausgewählte Zwecke spenden
- Persönliche Spendenziele und Statistiken verfolgen
- Pfandrückgabestellen in der Nähe suchen
- Auszahlungen und gemeinsame Spendenaktionen simulieren

## Technologie

Entwickelt mit HTML, CSS und JavaScript als installierbare Progressive Web App (PWA).

## Projektstatus

**Demo / Prototyp.** Es werden keine echten Pfandbons eingelöst und keine tatsächlichen Zahlungen oder Spenden ausgeführt. Nutzungsdaten werden lokal im Browser gespeichert.
